# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report them privately through GitHub:
[**Report a vulnerability**](https://github.com/mdg-labs/berth/security/advisories/new)
(Security tab → Advisories → Report a vulnerability).

Include the affected version or commit, a description of the issue, steps to
reproduce and the impact you expect. You will get an acknowledgement, and the
fix is coordinated with you in the private advisory before it is disclosed.

## Supported versions

Fixes land on `main` and ship in the next release. Only the latest release is
supported.
